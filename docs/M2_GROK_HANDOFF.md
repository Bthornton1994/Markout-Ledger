This is the bounded build task for the implementer (Grok). It implements [M2_DATA_CONTRACT.md](M2_DATA_CONTRACT.md) for the feed selected in [M2_DATA_SOURCE_DECISION.md](M2_DATA_SOURCE_DECISION.md), **Kraken spot `BTC/USD`** over the public WebSocket API v2 (`book` at depth 100 with its in-band snapshot and per-message CRC32 checksum, `trade`, `instrument`; adapter `kraken-spot-ws2`, contract §8), and nothing else. **Gate.** Nothing in this document is started until an independent read-only QA has cleared the corrected venue contract at the commit named in the pull request's QA request, and the owner has said so. Section 0 is a prerequisite that lands as its own PR before section 1 is started.

## 0. Prerequisite PR-0: versioned fixed-point precision migration

Why: contract §5.5. The selected instrument's quantity increment is `0.00000001` (`qty_precision` 8) and the engine's `QTY_SCALE` is `1e-6`; the normalizer refuses the instrument (R5) on the current engine because a quantity like `0.00000001` cannot be represented without rounding, and rounding is forbidden. Prices (`price_precision` 1, increment `0.1`) already fit.

**P0, before any code (owner only, no PR, and only after the owner has met conditions C2 and C3 of M2_DATA_SOURCE_DECISION.md §1, because it is automated access to the venue).** From a host in a jurisdiction the venue serves, operated by a person in one, take one public instrument snapshot (`{"method":"subscribe","params":{"channel":"instrument","snapshot":true}}` on `wss://ws.kraken.com/v2`, or `GET https://api.kraken.com/0/public/AssetPairs`) and list every pair with `qty_precision <= 6` **and** `price_precision <= 6` (REST: `lot_decimals <= 6` and `pair_decimals <= 6`), with `status`. Record `BTC/USD`'s values. If the owner substitutes a listed pair that meets the evaluation objective (a liquid USD spot market), PR-0 is skipped and the symbol in this handoff and in contract §8 changes; otherwise PR-0 proceeds. Reference data only; no market data is captured, the venue's payload is never committed, and what the PR carries is the owner's own derived statement (pair names, precisions, increments, status, and the date).
